# ShinkaEvolve: К Открытой и Эффективной Эволюции Программ

**Авторы:** Robert Tjarko Lange, Yuki Imajuku, Edoardo Cetin (Sakana AI)

## Краткое описание

ShinkaEvolve — это open-source фреймворк, который революционизирует научные открытия, управляемые большими языковыми моделями (LLM). Система достигает беспрецедентной эффективности выборки, находя решения мирового класса всего за 150 оценок вместо тысяч, требуемых существующими подходами.

## Ключевые инновации

### 1. Адаптивная выборка родителей
- Балансирует исследование и эксплуатацию через взвешенную комбинацию производительности и новизны
- Использует двухкомпонентную систему: α для производительности, (1-α) для новизны
- Динамически адаптируется в зависимости от состояния эволюции

### 2. Отклонение выборки новизны кода
- Эффективное исследование пространства поиска через семантическое сходство
- Комбинирует эмбеддинги кода с LLM судьями новизны
- Предотвращает застревание в локальных оптимумах

### 3. Стратегия ансамбля LLM на основе бандитов
- Алгоритм UCB1 для адаптивного выбора LLM
- Автоматически адаптируется к развивающимся состояниям программ
- Максимизирует эффективность мутаций

### 4. Революционная эффективность выборки
- Достигает результатов мирового уровня с порядково меньшим количеством оценок
- Пример: упаковка кругов решена за 150 оценок против тысяч в традиционных методах

## Архитектура системы

### Основные компоненты
- **Движок эволюции**: Центральный оркестратор с раннером, семплером и оболочкой оценки
- **База данных программ**: Архивы, островные популяции, стратегии отбора
- **LLM клиенты**: Поддержка OpenAI, Azure OpenAI, Anthropic, Google, DeepSeek
- **Редактирование кода**: Мутации через diff патчи, полные замены, кроссовер
- **Система запуска**: Выполнение заданий на локальных машинах и Slurm кластерах
- **Промпты**: Специализированные промпты для различных типов мутаций
- **Web интерфейс**: Визуализация прогресса эволюции в реальном времени

### Ключевые паттерны
- **Островная эволюция**: Множественные популяции развиваются параллельно
- **EVOLVE-BLOCK маркеры**: Целенаправленная эволюция отмеченных секций кода
- **Интеграция оценки**: Программы должны реализовывать функцию `run_experiment()`
- **Конфигурация Hydra**: Все эксперименты настраиваются через YAML файлы

## Экспериментальные результаты

1. **Упаковка кругов**: State-of-the-art результаты за 150 оценок
2. **AIME математическое рассуждение**: Превосходные показатели на соревновательных задачах
3. **ALE-Bench программирование**: Высокая производительность в конкурентном программировании
4. **Mixture-of-Expert балансировка нагрузки**: Оптимизация функций потерь

### Преимущества производительности
- **Радикальное улучшение эффективности**: От тысяч до сотен оценок
- **Масштабируемость**: Поддержка от локальных экспериментов до крупных кластеров
- **Универсальность**: Применимо к широкому спектру научных задач

## Технические детали

### Алгоритм выборки родителей
```
parent_weight = α × performance_score + (1-α) × novelty_score
```
где α динамически адаптируется в зависимости от фазы эволюции.

### Оценка новизны кода
- Семантическое сходство через эмбеддинги кода
- LLM судьи для качественной оценки новизны
- Пороговые значения для отклонения похожих решений

### UCB1 для выбора LLM
- Верхняя доверительная граница для баланса исследования/эксплуатации
- Адаптивное обучение предпочтений LLM для конкретных задач
- Максимизация совокупного вознаграждения за мутации

## Практическое применение

### Установка и использование
```bash
# Создание окружения
uv venv --python 3.11
source .venv/bin/activate
uv pip install -e .

# Запуск эксперимента
shinka_launch variant=circle_packing_example

# Визуализация
shinka_visualize --port 8888 --open
```

### Конфигурация задач
- **Скрипт оценки**: `evaluate.py` с функцией `run_shinka_eval()`
- **Начальная программа**: `initial.py` с маркерами `# EVOLVE-BLOCK`
- **YAML конфигурация**: Определение параметров задачи

ShinkaEvolve устанавливает новый стандарт в области эволюционных алгоритмов, управляемых LLM.
